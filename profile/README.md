## 👋 Who we are

**CodeCanon LLC** builds open-source and commercial developer tools — React/TypeScript component libraries, headless data primitives, and custom software for web and mobile.

We care about libraries that are **headless, composable, and fully typed**: bring your own UI, storage, and runtime.

## 📦 What we build

| Package | What it does | |
| --- | --- | --- |
| [`@codecanon/waraq`](https://github.com/CodeCanon-LLC/codecanon-waraq) | Canva-like drag-and-drop design editor for React, built on shadcn/ui — zoom/pan canvas, snapping, serializable state, print & export | [Demo →](https://codecanon.dev/waraq/demo) |

## 🛠 How we work

- **TypeScript-first** — Zod schemas for every core type, dual ESM/CJS builds
- **Runtime-agnostic** — browsers, Node.js, Bun, Deno, and edge
- **Pluggable by design** — swap adapters instead of forking the library
